Module 5 : Mémoire Partagée

Accès direct à la mémoire partagée et mapping de fichiers.

1. Concept de Mémoire Partagée

La mémoire partagée est le mécanisme d'IPC le plus rapide car il ne nécessite pas de copie de données entre les processus via le noyau. Les processus accèdent directement au même segment physique.

  • Avantage : Performance maximale, accès direct.
  • Inconvénient : Pas de synchronisation implicite (nécessite des sémaphores ou mutex).

2. Mémoire Partagée POSIX

Utilise les fonctions de la bibliothèque librt.

  • shm_open() : Crée ou ouvre un objet mémoire partagée (similaire à open).
  • ftruncate() : Définit la taille du segment.
  • mmap() : Attache le segment dans l'espace d'adressage du processus.
Attention : Les pointeurs ne peuvent pas être partagés directement entre processus car les adresses de base peuvent différer. On utilise des offsets par rapport au début du segment.

3. Implémentation avec mmap

#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <stdio.h>

int main() {
    // Création d'un segment de mémoire partagée
    int fd = shm_open("/my_shm", O_CREAT | O_RDWR, 0666);
    ftruncate(fd, 4096); // Taille de 4 Ko

    // Mapping du segment en lecture/écriture
    void* ptr = mmap(NULL, 4096, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    
    if (ptr == MAP_FAILED) {
        perror("mmap");
        return 1;
    }

    // Utilisation du segment comme un tableau classique
    int* data = (int*)ptr;
    data[0] = 42; // Accessible par tous les processus utilisant ce nom

    munmap(ptr, 4096);
    close(fd);
    return 0;
}

Entraînement : Création d'un Buffer Partagé

Écrivez un programme qui crée une zone mémoire partagée et y écrit un message. Un second processus (ou une seconde instance) doit pouvoir lire ce même message.

QMC de Validation

1. Pourquoi ne peut-on pas partager des pointeurs directement dans un segment mmap ?

Parce que les adresses physiques sont différentes.
Car le système d'exploitation interdit l'accès aux pointeurs.
Parce que la mémoire est protégée par un mutex.
