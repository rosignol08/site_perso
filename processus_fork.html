Module 1 : Processus et Fork

Ce module explore les fondements de la gestion des processus sous POSIX.

1. Concepts Fondamentaux

Un processus est une entité active du système, possédant son propre espace d'adressage (code, données, pile), un identifiant unique (PID) et des ressources allouées par le noyau.

  • Identité : PID (Process ID), UID/GID (User/Group IDs).
  • Espace d'adressage : Isolé pour chaque processus. Deux processus ne peuvent pas accéder directement à la mémoire de l'autre sans mécanismes spécifiques (IPC).
Note Technique : Le passage du mode utilisateur au mode noyau se fait via des appels système (System Calls), comme fork(), exec() ou wait().

2. Création de Processus avec fork()

La primitive fork() crée une copie quasi-identique du processus appelant.

  • Retour dans le Père : Le PID du nouveau processus fils.
  • Retour dans le Fils : Zéro (0).
  • Échec : -1.

3. Exécution de nouveaux programmes (exec)

La famille exec remplace l'image du processus actuel par une nouvelle image.

  • execl() : Liste d'arguments.
  • execv() : Vecteur d'arguments.
  • execle() : Avec un environnement personnalisé.

4. Synchronisation Père/Fils (wait)

Le processus père peut attendre la fin de ses fils via wait() ou waitpid().

#include <sys/wait.h>
#include <unistd.h>

int main() {
    pid_t pid = fork();
    if (pid == 0) {
        // Code du fils
        printf("Je suis le fils\n");
    } else if (pid > 0) {
        // Code du père
        wait(NULL); // Attend que le fils termine
        printf("Le fils a terminé\n");
    }
    return 0;
}
